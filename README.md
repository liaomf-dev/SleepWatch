# 睡眠觀察 App（Android）

整夜監聽聲音，自動錄下打呼、說夢話與其他夜間聲響，起床後可以重播，並顯示整晚的睡眠聲音分數。

## 功能
- 背景整夜記錄（螢幕關閉也會持續），通知列會顯示「睡眠觀察中」
- 可選擇延遲 15 分鐘才開始偵測，避免錄到入睡前的聲音
- 自動把聲音分成：打呼／說話（夢話）／其他聲響，每段都可以播放
- 每晚結果：分數、打呼段數與時間比例、說話次數、安靜時間比例、整晚音量圖
- 只在偵測到明顯聲音時才存錄音（每段最長 30 秒，一晚最多 120 段），錄音只存在手機裡

## 編譯
與「海拔位置」相同：上傳到 GitHub 新的 repository，並建立 `.github/workflows/build.yml`，
到 Actions 下載 `SleepWatch-apk`。

## 注意
- 分類為依聲音特徵自動判斷，不一定完全準確
- 分數只依聲音與時長估算，不能取代醫療檢查
- 需要 Android 7.0 以上
